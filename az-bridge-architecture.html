Claude Code 通信方式

A2A 通信协议 — SSE 流式 + 轮询降级

SSE 流式模式 (优先)

stream: true 客户端发送 sendMessage 并设置 stream: true，服务端返回 Content-Type: text/event-stream SSE 事件流。 事件格式: event: task → event: message → event: done。 通过 spawn_status_tracker 包装 CLI 事件流，实时追踪 task 状态转换 (SUBMITTED→WORKING→COMPLETED)。

Polling 轮询降级

fallback 服务端不支持 SSE 时返回标准 JSON，客户端自动降级为 getTask 轮询 (3s 间隔)。 每 3 次轮询发送进度事件: 等待远程 Agent 响应...(Ns)，前端显示等待时间。 直到 task status 变为 completed/failed，从 task.artifacts 或 task.messages 提取响应。

多格式消息兼容 支持三种消息格式自动检测: parts[] (A2A标准) / content: string (简单文本) / content: [{type,text}] (OpenAI风格)

Thread 模式 — 持久进程

stdin/stdout 启动 claude --print --output-format stream-json --input-format stream-json 持久进程。 通过 stdin 写入 JSON 消息，从 stdout 读取 JSONL 流式响应。进程跨消息复用，支持 --resume 恢复会话。 5 个进程池上限，LRU 淘汰，5 分钟空闲自动回收。

Channel 模式 — 一次性调用

one-shot 每次请求 spawn 一个新进程，消息作为命令行参数传入。 Channel 自行管理上下文（滑动窗口 + 自动摘要），不依赖进程复用。进程执行完毕自动退出。

不是 ACP 协议 AgentsZone 通过 stdin/stdout JSON Streaming 直接控制 Claude Code CLI 进程，不使用 Anthropic ACP 或其他中间协议。

数据流：Bridge Workspace 加载

1. 用户打开 Settings → Remote Connections → + Add
填入远程 http://IP:7878，点 Save 创建连接记录
2. 用户点 Test → 健康检查
Rust 后端通过 remote_connection_test IPC 发送 getAgentCard，获取远程 AgentCard
3. 状态变为 Online → BridgeWorkspacePanel 渲染
isBridgeEndpoint() 检查 agent_card.supported_operations 是否包含 bridge.* 操作
4. useBridgeWorkspace.refresh() 并行加载
同时请求 bridge.getWorkspaceInfo + bridge.getAgents，返回 workspace 元信息和 agent 列表
5. 渲染远程 Agent 卡片
每个 agent 显示 emoji + name + runtime_type，点击可展开文件浏览
6. 点击 Agent → bridge.listFiles
请求 {"agent_id":"default"}，返回文件/目录列表（含 name, is_dir, size, modified）
7. 点击文件 → bridge.readFile
请求 {"agent_id":"default","file_path":"IDENTITY.md"}，返回文件内容 + MIME 类型（只读）
8. 每 30 秒自动轮询刷新
POLL_INTERVAL = 30000ms，定时调用 refresh() 更新 workspace 和 agent 状态

API 方法总览

标准 A2A 方法
getAgentCard 获取 agent 身份和能力 STD
sendMessage 发送消息 (支持 stream:true → SSE) STD
streamMessage 流式消息 (SSE event-stream) STD
getTask 查询任务状态 STD
cancelTask 取消任务 STD
listTasks 列出任务 STD
Bridge 扩展方法
bridge.getWorkspaceInfo workspace 元信息 EXT
bridge.getAgents 远程 agent 列表 EXT
bridge.listFiles 文件/目录浏览 EXT
bridge.readFile 文件内容读取 EXT

安全机制

路径沙箱
所有文件操作限制在 workspace 基目录内，无法访问外部文件
遍历防护
拒绝 ..、绝对路径、反斜杠，sanitize + canonicalize 双重验证
只读文件
listFiles / readFile 均为只读操作，不暴露写入能力
